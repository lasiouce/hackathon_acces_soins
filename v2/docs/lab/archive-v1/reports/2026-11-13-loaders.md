# Loaders: DREES stock + Omphale population → tidy parquet

> **Headline:** the detailed cells reproduce each file's own France total within
> **0.13 %** (exactly 0 % for 6 of 7 series). The output is **1.57 M** stock
> rows and **642 k** population rows, rebuilt from the raw Excel files in
> **~25 s** (measured).

## Question
Can the stock-flow model (H1) and the K1 backtest read one consistent table
per source, without double counting the "Ensemble" (all) levels?

## How
- **Data:** see `docs/lab/explorations/data-inventory.md` (update section).
- **Method:** `sante/load.py` (`uv run python -m sante.load`).
  - Keep the detailed level of every dimension, with the activity sector
    kept at its aggregate.
  - Normalise département codes to Insee COG.
  - Parse the age bands into bounds.
  - Map RPPS and ADELI modes onto 3 shared modes (`mode3`).
  - Match Omphale zones (which use names) to codes, using every name
    variant seen in the DREES files.
- **Outputs** (in `data/processed/`):
  - `stock.parquet` · `population.parquet`;
  - `checks.csv`: per series × year, sum of detailed cells vs national
    total.

## ⚑ What could make it wrong
- **Kiné RPPS cells sum 0.13 % off the national total.** The likeliest
  cause is small-count suppression; not investigated.
- **The kinés' 2017 register switch** (ADELI → RPPS) is not sized yet. In
  ADELI, `mode3` merges libéral and mixte.
- **Not in Omphale** (excluded from densities):
  - "COM ou étranger" (code 999): ≤ 175 doctors per year;
  - pharmacists coded to undivided Corse (`20`): 69 person-years in total.
- **The médecins file mislabels département 62** as "Nord-Pas-de-Calais".
  The display name is taken from the other files.
- **Age bands differ**: the top band is 75+ for doctors, 65+ for the
  others. Omphale uses 5-year bands to 95+.
- **Nurses:**
  - private-practice nurses stop at **2023**;
  - salaried nurses are not loaded yet (marginals only; raking session
    proposed).

## → What it changes
- **H1 and K1 can be built now.** For médecins, dentistes, pharmaciens and
  sages-femmes the stock is complete from 2012 (fit 2012–2018, project to
  2026). For kinés it is complete from 2017, a 9-year series.
- Densities per 100k by département and year can be computed for every
  profession with stock data. This is the stage-1 output.
